# How we talk about things
# One term per line: "term(s): what it means". Lines starting with # are
# comments and aren't sent to the model. Event keys change every year
# (2026miwmi, 2027miwmi, ...), so name the event code, not the key.

worlds, champs, the Championship: the FIRST Championship, in Houston (2017–2019 there was a second one, in St. Louis then Detroit; TBA event types "Championship Division" and "Championship Finals"). "Making worlds" = qualifying for or attending it.
Einstein: the Championship's final playoff, between the division winners (event type "Championship Finals").
GVSU, Grand Valley: the FIM District West Michigan Event, held at Grand Valley State University in Allendale, MI (event code miwmi).
states, MSC, state championship, DCMP: the FIRST in Michigan State Championship (FiM District Championship, event code micmp; its divisions are separate events).
